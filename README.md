# Innventure

> **Adventure Begins at Check-In**

Innventure is a full-stack travel and property booking platform inspired by modern hospitality and adventure-based applications like Airbnb and Booking.com.

This project is being built using a **microservices architecture** with Spring Boot and a modern frontend powered by Next.js.

---

# 🚀 Tech Stack

## Frontend
- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Axios
- React Query
- ShadCN UI

## Backend
- Java 21
- Spring Boot 3
- Spring Security
- Spring Data JPA
- H2 Database (Development)
- PostgreSQL (Planned)
- Maven

## Future Integrations
- Kafka
- Redis
- Spring Cloud Gateway
- Docker & Docker Compose
